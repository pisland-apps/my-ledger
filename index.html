Surrender value history
Figures copied from the insurer's statements

Copy the figures from the insurer's statement. Guaranteed = guaranteed cash value (plus the reversionary-bonus cash value, if any). Dividend = accumulated dividend. Terminal bonus = non-guaranteed terminal dividend / bonus. Dividend and Terminal bonus accept a sum such as 12000 + 3500.50. Total fills in by itself; or type the statement's Total — if exactly one part is empty it is worked out, and any difference (for example advance premium or accumulated cash payment) shows as "Other". The latest entry is the value shown on the policy.
